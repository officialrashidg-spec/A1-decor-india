Preview:
1. Extract the ZIP.
2. Open index.html in a browser. Internet is required for the sample project photos and Google Fonts.

Publish free with GitHub Pages:
1. Sign in to https://github.com
2. Create a new public repository, for example: a1-decor-india
3. Upload index.html and the assets folder (keep the folder structure).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. GitHub will provide your free address: https://YOUR-USERNAME.github.io/a1-decor-india/
